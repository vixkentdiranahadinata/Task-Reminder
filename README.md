# TaskReminder

A gamified daily task planner built as a Single Page Application (SPA).

## Structure
-   **Files**: `TaskReminder.html` contains the entire application (HTML, CSS, JS).
-   **Architecture**: Client-side React application.

## Tech Stack
-   **Languages**: HTML, CSS, JavaScript.
-   **Libraries**: React (via CDN), TailwindCSS (via CDN).
-   **Backend**: Firebase (Auth & Firestore).
-   **AI**: Google Gemini API.
-   **Tools**: Node.js is **OPTIONAL**. It is only useful if you want to run a local server (`npx serve`) or if you plan to upgrade the project build system later.


## Dependencies (CDNs)
The application doesn't require `npm install`. It uses the following libraries via CDN:
1.  **React 18** (UI Framework)
2.  **Tailwind CSS** (Styling)
3.  **Babel** (JSX Compilation)
4.  **Firebase v11.0.2** (Backend: Auth, Firestore)
5.  **Google Gemini API** (AI Features)
